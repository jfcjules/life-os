# US-05 - Filter calendar by space

## User Story

As a Life OS user, I want to filter my calendar by space, so that I can focus on all plans, my personal plans, or shared plans when needed.

## Estado actual / Problem Statement

The Calendar concept includes All, Personal, and Couple as the first filters, but the product needs a clear expectation for how those filters help the user focus. Without this behavior, the calendar may show the correct labels but not provide a meaningful way to reduce noise between individual and shared plans.

## Scope

- Provide filter options for All, Personal, and Couple.
- Make All the combined calendar view.
- Let the user focus on Personal events.
- Let the user focus on Couple events.
- Keep filters simple and visible near the Calendar view controls.
- Preserve a calm visual treatment for selected and unselected filters.

## Out of Scope

- Category filters such as Home, Pets, Work, or Health.
- Saved custom filters.
- Search.
- Advanced sorting.
- Permissions-based filtering.
- Filtering connected items independently from calendar context.

## Acceptance Criteria

1. A user can see the available space filters on the Calendar screen.
2. A user can understand that All includes both Personal and Couple events.
3. A user can focus the calendar on Personal events.
4. A user can focus the calendar on Couple events.
5. The selected filter is visually clear without feeling loud.
6. The filtering experience does not introduce additional spaces or category systems beyond the first concept.
