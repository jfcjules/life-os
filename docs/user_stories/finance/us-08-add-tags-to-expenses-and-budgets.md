# US-08 - Add tags to expenses and budgets

## User Story

As a Life OS user, I want to add tags to my expenses and budgets, so that I can organize and identify my financial information more easily.

## Estado actual / Problem Statement

The Finance concept allows users to create and manage expenses and budgets, but there is not yet a defined user-facing expectation for adding tags to these items. Without tags, users have limited flexibility to organize their financial information according to their own needs and identify related expenses or budgets.

## Scope

- Allow the user to add one or more tags to an expense.
- Allow the user to add one or more tags to a budget.
- Provide a clear way to select an existing tag when creating or editing an expense or budget.
- Allow the user to create a new tag when assigning tags to an expense or budget.
- Display assigned tags clearly when viewing an expense or budget.
- Allow the user to add, change, or remove tags after an expense or budget has been created.
- Allow expenses and budgets to exist without tags.
- Keep tags simple and flexible without requiring a predefined financial taxonomy.
- Keep the experience aligned with the calm Life OS visual language.

## Out of Scope

- Automatically assigning tags based on expense or budget information.
- Required tags for expenses or budgets.
- Advanced tag hierarchies or nested tags.
- Automatic categorization of financial items.
- Tag-based financial analytics or reporting.
- Sharing or synchronizing tags between external financial services.
- Automatic tag suggestions.
- Deleting or merging tags across the entire Finance section.

## Acceptance Criteria

1. A user can add one or more tags to an expense.
2. A user can add one or more tags to a budget.
3. The user can select an existing tag when creating or editing an expense or budget.
4. The user can create a new tag when assigning tags to an expense or budget.
5. Assigned tags are clearly displayed when viewing an expense or budget.
6. A user can add or remove tags after an expense or budget has been created.
7. Tags are optional and are not required to create an expense or budget.
8. Removing a tag does not delete or modify the associated expense or budget.
9. The same tag can be assigned to multiple expenses and budgets.
10. The tagging functionality does not imply automatic categorization, advanced tag hierarchies, or financial analytics are already available.
