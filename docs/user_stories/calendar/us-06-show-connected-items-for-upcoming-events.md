# US-06 - Show connected items for upcoming events

## User Story

As a Life OS user, I want to see items connected to upcoming events, so that I can prepare for plans without having to check each life area separately.

## Estado actual / Problem Statement

The Calendar concept should help the user notice preparation and follow-up around events, not only show event times. Without connected items, the user may miss related reminders, chores, pet care, or finance context that affects whether an event is actually ready to happen.

## Scope

- Show a Connected items section in the Calendar concept.
- Include related items that help the user prepare for or follow up on upcoming events.
- Support relationship types from the first concept, such as Reminder, Chore, Finance, and Pet.
- Show the related item's title, relationship type, due timing, and space.
- Keep the section selective rather than exhaustive.

## Out of Scope

- Automatically generating connected items.
- Editing the connected item from the Calendar screen.
- Showing every possible related item.
- Final cross-module data modeling.
- Notifications, reminders, or automation rules.
- Deep linking into future detail pages.

## Acceptance Criteria

1. A user can see a dedicated area for items connected to upcoming events.
2. A user can understand why a connected item matters before or after an event.
3. A user can see the connected item's relationship type, due timing, and space.
4. The section highlights useful preparation context without becoming an exhaustive task list.
5. The experience supports the idea of connected life areas without requiring the user to understand an underlying data model.
